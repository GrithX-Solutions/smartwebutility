Convert HTML to Markdown locally

We designed this HTML to Markdown converter for content migration and editing workflows where existing HTML needs to become portable Markdown. Common use cases include moving CMS content into documentation, cleaning copied article markup, preparing text for a repository, converting notes, or simplifying content before importing it into a Markdown publishing system.

Semantic headings and paragraphs

HTML headings become Markdown headings, and the converter retains paragraph structure without carrying across CSS classes or presentational layout attributes.

Links and emphasis

Anchor elements become Markdown links, while strong and emphasis elements map to familiar Markdown syntax.

Lists and code

The converter turns ordered and unordered lists, inline code and preformatted code blocks into readable Markdown representations.

GFM tables and tasks

When you enable GFM support, the converter can represent compatible HTML tables, task-list items and strikethrough markup with GitHub Flavored Markdown syntax.

What happens to scripts, styles and embedded content

The converter parses the input as an HTML document but does not execute it. It removes active or non-content elements such as script, style, iframe, object, embed, template and noscript before conversion. The goal is to convert document content, not reproduce a webpage runtime.

HTML layout does not map perfectly to Markdown

Markdown intentionally has a smaller formatting vocabulary than HTML. Complex grids, forms, positioned elements, interactive widgets, deeply nested tables and CSS-driven presentation may not have a faithful Markdown equivalent. The output focuses on readable content structure rather than pixel-perfect webpage reconstruction.

Tables need a Markdown dialect

Standard Markdown does not define tables, while GitHub Flavored Markdown does. Keep GFM support on when table preservation matters. Turn it off when your destination accepts only a minimal Markdown subset and you prefer the converter to simplify unsupported table markup.

Why CSS classes and inline styles disappear

Markdown describes content structure rather than browser presentation. Classes, IDs, inline styles, data attributes and most layout-specific properties therefore do not survive normal conversion. That is expected behavior and often desirable when migrating content out of a page builder or CMS.

Conversion is not webpage scraping

This tool converts HTML that you provide. It does not fetch a remote URL, run JavaScript on another site, bypass access controls or attempt to extract content from an arbitrary webpage. If JavaScript renders a website dynamically, obtain the HTML you are authorized to use before converting it here.

Frequently asked questions

Can it convert HTML tables to Markdown?

Yes, for compatible tables when you enable GFM support.

Does it execute scripts in the HTML?

No. The converter parses the source as data and removes active embedded elements before conversion.

Will CSS be converted?

No. Markdown does not provide a general equivalent for CSS layout and styling.

Can I convert an HTML file?

Yes. Open a local .html or .htm file up to 5 MB.

Is my HTML uploaded?

No. Conversion runs locally in browser JavaScript on this page.
