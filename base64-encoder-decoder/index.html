Encode and decode Base64 online

Use Encode mode for text that needs a Base64 representation and Decode mode for Base64 that should become readable UTF-8 text. The tool supports standard Base64 and the URL- and filename-safe alphabet commonly called Base64URL. It also accepts a local file in Encode mode and converts the file bytes to Base64 without uploading the file to Smart Web Utility.

UTF-8 text

The text encoder converts Unicode characters to UTF-8 bytes before Base64 encoding, so accented text, emoji and non-Latin scripts can round-trip correctly.

Local file encoding

Choose a file up to 5 MB to encode its raw bytes. The browser reads the file locally and writes the Base64 result to the output panel.

Base64URL

Base64URL uses - and _ instead of + and /. This tool removes trailing padding when it produces Base64URL output.

Copy and download

Copy the result, swap text output back into the input, or download the displayed output as a text file.

Base64 and Base64URL are not the same encoding alphabet

RFC 4648 defines standard Base64 and a URL- and filename-safe variant. Standard Base64 uses + and / for two alphabet positions and normally uses = padding. Base64URL replaces those two characters with - and _; protocols that know the data length can omit padding. Choose the variant required by the system you are integrating with instead of treating them as interchangeable.

Encode a file to Base64 without reading it as text

The file encoder reads raw bytes rather than interpreting the file as UTF-8. That makes it suitable for binary input such as a small image, certificate, archive fragment or test fixture when you need its Base64 representation. The current file workflow caps input at 5 MB to avoid tying up browser memory. The output is Base64 text; this tool does not create a data URI or guess a MIME type.

The decoder returns UTF-8 text, not arbitrary binary files

Decode mode validates the Base64 alphabet, restores Base64URL padding when needed, decodes the bytes and then requires those bytes to form valid UTF-8. If the decoded bytes represent an image, archive, executable or another binary format, this text decoder reports an error instead of displaying corrupted characters. That boundary is intentional: use a binary-aware workflow when you need to reconstruct an arbitrary file.

Whitespace, padding and invalid Base64 input

The decoder ignores whitespace in pasted Base64 text before validation. Standard Base64 input must then use the standard alphabet with valid trailing padding and a length compatible with four-character encoding groups. Base64URL mode accepts the URL-safe alphabet and restores omitted padding before decoding. A successful decode proves that the text can be decoded as UTF-8; it does not prove that the decoded value is trustworthy or safe.

Common Base64 workflows

API debugging

Inspect Base64 values from JSON payloads, logs or test fixtures and verify that text round-trips as expected.

JWT-related data

Work with Base64URL text used by token formats. For JWT claims, the JWT Decoder also parses header and payload JSON.

Small file encoding

Create a Base64 representation of local binary test data without sending the file to a server.

Interoperability checks

Compare standard Base64 with Base64URL output when an API, filename or URL context requires a specific alphabet.

Base64 is encoding, not encryption

Anyone who receives a Base64 value can normally decode it. Do not use Base64 to protect passwords, API keys or confidential data. Encoding changes representation; it does not provide secrecy, authentication or integrity protection.

Frequently asked questions

Can this Base64 encoder handle files?

Yes. Encode mode accepts a local file up to 5 MB and converts its raw bytes to Base64 in your browser.

Can it decode Base64 into an image or other binary file?

No. Decode mode intentionally returns valid UTF-8 text only. It rejects decoded bytes that are not valid UTF-8.

Does Base64URL always remove padding?

This tool removes padding when it creates Base64URL output. Other protocols may require different padding rules, so follow the specification for the system you are using.

Is Base64 encryption?

No. Base64 is a reversible binary-to-text encoding and does not provide confidentiality.

Does Smart Web Utility upload my text or file?

No. Base64 processing runs in browser JavaScript.
