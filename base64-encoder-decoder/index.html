Encode Base64 online

Use Encode mode to convert regular UTF-8 text into Base64. This is useful when working with APIs, authorization headers, data payloads, configuration values and other systems that represent binary or text data using Base64.

Decode Base64 online

Use Decode mode to convert valid Base64 back to readable UTF-8 text. Invalid Base64 input is rejected instead of silently producing corrupted output.

Base64 vs Base64URL

Standard Base64 uses the characters + and / in its alphabet and commonly uses = padding. Base64URL uses URL-friendly substitutions such as - and _, and padding is often omitted. This tool supports both normal Base64 and the URL-safe form so you can work with API payloads, tokens and web-safe encoded values.

UTF-8 text, Unicode and Base64

Base64 represents bytes, not human-readable characters. When you encode text, the text must first be represented as bytes. This tool uses UTF-8-aware handling so non-Latin scripts and emoji can be converted without relying on ASCII-only browser behavior.

Base64 padding and invalid input

The trailing = characters sometimes seen in Base64 are padding used to complete the encoded block shape. Some URL-safe formats omit that padding. During decoding, malformed input should be treated as an error rather than silently accepted as trustworthy data.

Base64 is encoding, not encryption

Anyone who has the encoded value can decode it. Do not use Base64 to protect passwords, API keys or confidential data. Its purpose is representation and transport compatibility, not secrecy or authentication.
