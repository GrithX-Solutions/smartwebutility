Worldwide DNS propagation checker

What this live DNS propagation check measures

It sends the same DNS query from 12 live probe locations and compares the answers returned for the selected record type. The result is a real multi-country sample, not a simulated propagation percentage.

Live country-level probes

Each row represents a distributed probe in one of the selected countries. After the lookup finishes, the country stays in place and its current DNS answer is filled into the same row.

Useful after DNS changes

Run the check after a hosting migration, A or AAAA update, mail-provider change, nameserver move, CNAME change or DNS-based verification update.

Different answers are evidence

If locations disagree, one resolver path may still have a cached answer, an authoritative server may be inconsistent, or the domain may intentionally use geo-aware DNS.

Matching answers are a sample

Agreement across all tested probes is strong evidence that those paths see the same value. It is not proof that every ISP, enterprise resolver or device cache worldwide has refreshed.

Choose the record that changed. Checking the wrong type can make a healthy DNS setup look incomplete.

How to read worldwide DNS propagation results

Every row shows the new value

The tested probe paths currently agree on the new answer. If users still reach the old service, continue with local DNS, browser, CDN, HTTP or application troubleshooting.

Some rows show the old value

That pattern is consistent with independent resolver caches expiring at different times. Check the previous TTL and verify that authoritative DNS is already correct.

Every row shows the wrong value

Do not assume you only need to wait. Verify the domain's delegation and confirm you edited the DNS zone that is actually authoritative.

No answer for one record type

A missing answer can be valid. For example, a hostname can have an A record without having a CNAME. Test the record you intended to publish.

Common questions about global DNS propagation

What is a global DNS propagation test?

A global DNS propagation tool asks the same DNS question from multiple network locations and compares the answers. It helps show whether a recent DNS change is already visible through the tested resolver paths or whether some paths still return another value.

How long does DNS propagation take?

There is no single worldwide timer. Recursive resolvers cache answers independently, and the previous TTL is one of the main factors. Some paths can refresh quickly while others keep an older cached value until that cache expires.

Why can DNS answers differ between countries?

Independent caches can be at different stages after a change. Some services also intentionally return location-dependent answers through geo-aware DNS or CDN routing, so a difference is not automatically an error.

Does matching across 12 probes mean DNS is updated everywhere?

No. It means the tested probes currently agree. No public checker can query every recursive resolver, ISP, enterprise network, router and device cache on the internet.

Measurement methodology and limits

Smart Web Utility requests one live DNS measurement for each selected country through distributed Globalping probes. The homepage currently samples the United States, Canada, Brazil, United Kingdom, Germany, Netherlands, South Africa, India, Singapore, Japan, Australia and the United Arab Emirates. Probe city and network can vary between runs depending on available infrastructure.

This worldwide DNS propagation checker is designed to answer what the tested paths return now. It does not reconstruct historical DNS, guarantee a specific resolver is used in every country, or prove global convergence. Read our methodology and editorial standards for how diagnostic claims and limitations are handled.
