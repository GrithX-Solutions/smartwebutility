Convert Markdown to HTML in the browser

This converter turns Markdown source into HTML without sending the document to a Smart Web Utility API. It is useful for README content, documentation, static-site workflows, CMS migration, email templates, developer notes and any workflow where Markdown needs to become portable HTML markup.

GitHub Flavored Markdown

CommonMark-style Markdown is extended with useful GFM features including tables, task lists and strikethrough where the parser supports them.

Code blocks and inline code

Fenced code blocks and inline code are converted to semantic <pre> and <code> markup. This tool does not add syntax-highlighting JavaScript.

Links, lists and headings

Headings, ordered and unordered lists, blockquotes, emphasis, links and images are converted to their corresponding HTML elements.

Local file workflow

Open a local Markdown file up to 5 MB, copy the generated HTML source, or download the result as an HTML file.

Sanitized output is the default

Marked intentionally does not sanitize generated HTML. This page therefore passes the parsed result through DOMPurify by default before it reaches the output box, copy action, download action or preview. That removes dangerous markup and attributes according to DOMPurify's HTML profile while preserving ordinary Markdown-generated structure.

Turn off “Sanitize generated HTML” only when you deliberately need Marked's raw output, including embedded HTML from the Markdown source. Raw mode is useful for trusted authoring workflows, but the copied/downloaded result can contain active markup and must not be treated as safe user-generated HTML.

The preview stays sandboxed in both output modes

The on-page preview uses an iframe with an empty sandbox attribute plus a restrictive Content Security Policy. Scripts, forms, network connections, frames, objects, fonts and remote media are blocked; preview links also have pointer interaction disabled. This preview isolation is defense in depth and does not turn raw downloaded HTML into safe production content.

Single line breaks versus paragraphs

Standard Markdown normally treats a single newline inside a paragraph as whitespace rather than an HTML line break. Enable the line-break option when you need single newlines converted to <br>. Leave it disabled for the more common paragraph-based Markdown behavior.

What conversion preserves — and what it does not

The output preserves document structure represented by Markdown syntax, but it does not recreate a complete webpage design. CSS, fonts, page layout, external assets and JavaScript behavior are separate concerns. A Markdown table becomes an HTML table structure, for example, but it will not automatically inherit the styling of GitHub or another publishing platform.

Sanitization still does not define your application's trust policy

Default sanitization is safer than returning raw parser output, but a production application can have stricter requirements for links, images, allowed attributes, URL schemes or embedded content. Treat the generated HTML as a conversion result, then apply the destination application's own validation and content policy before storing or rendering untrusted submissions.

Frequently asked questions

Does it support Markdown tables?

Yes. The selected parser supports GitHub Flavored Markdown tables.

Can it convert a Markdown file?

Yes. Open a local .md or .markdown file up to 5 MB.

Is the generated HTML sanitized?

Yes, by default. The converter sanitizes Marked's HTML with DOMPurify before copy, download and preview. You can explicitly disable sanitization to obtain raw parser output for a trusted workflow.

Can raw Markdown HTML execute inside the preview?

The preview remains inside a sandboxed iframe with a restrictive Content Security Policy even when raw-output mode is selected. Raw copied or downloaded HTML is separate and can still contain active markup.

Does it add CSS?

No. The converter generates HTML structure, not a site-specific design system.

Is my Markdown uploaded?

No. Conversion runs in browser JavaScript on this page.
