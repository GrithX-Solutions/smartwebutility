Minify CSS without uploading the stylesheet

This CSS minifier parses and compresses CSS directly in browser JavaScript. It removes redundant formatting, shortens compatible values and produces compact output suitable for build artifacts, static sites, test fixtures and other workflows where smaller stylesheet source is useful.

Whitespace and formatting

The parser removes indentation, line breaks and unnecessary spaces where it can do so without changing the stylesheet grammar.

Shorter equivalent values

The minifier can rewrite compatible values to shorter forms. For example, it can represent some colors, zero values and redundant syntax more compactly.

Structural optimization

Optional restructuring can merge compatible rules and declarations for additional savings. The tool disables it by default because changing stylesheet structure is more aggressive than basic compression.

Measure the result

The tool reports input bytes, output bytes and percentage saved so you can evaluate real compression rather than assuming every stylesheet benefits equally.

Why structural optimization is opt-in

CSS optimizers can sometimes combine declarations or rules that appear equivalent. In normal stylesheets this can reduce size, but CSS ordering, cascade behavior, browser quirks and framework-generated selectors can make aggressive restructuring harder to review. The default mode therefore compresses without structural merging.

Minification is not the same as removing unused CSS

This page compresses CSS that you provide. It does not inspect an entire website to determine which selectors are unused. Removing unused CSS requires analyzing the HTML, templates, runtime states, responsive breakpoints and JavaScript-driven classes that may appear only under specific conditions.

CSS compression and HTTP compression are different

Minification reduces source characters before transfer. Brotli or gzip compression reduces bytes during network delivery. You can use both together, but they solve different parts of the delivery process. A stylesheet may already compress well over HTTP, so actual transfer savings can be smaller than the raw source-size reduction shown here.

Custom properties, modern syntax and generated CSS

Modern CSS can include custom properties, container queries, nested syntax, advanced color functions and framework-generated selectors. Keep the original stylesheet in version control and test the minified output in the browsers you support, especially when your source uses newer or tool-specific syntax.

When CSS minification helps most

Minification works best as part of a repeatable production build where developers keep readable source CSS and deploy a compact derivative. Permanently replacing human-readable source with minified code makes debugging and review harder.

Frequently asked questions

Does CSS minification change styling?

Basic compression aims to preserve CSS behavior, but you should test all production output, especially when you enable structural optimization.

Does this remove unused selectors?

No. It compresses the CSS provided; it does not crawl a site or determine whether selectors are unused.

Can I upload a CSS file?

You can open a local .css file up to 5 MB. Browser JavaScript processes the file locally.

What does structural optimization do?

It allows the minifier to restructure compatible rules and declarations to reduce source size further.

Is my CSS sent to the server?

No. Minification runs locally in browser JavaScript.
