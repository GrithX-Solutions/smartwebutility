Convert CSV to formatted JSON objects or arrays

This CSV to JSON converter parses comma-separated or other delimited rows and generates readable JSON in your browser. When the first row is used as a header, each header becomes a JSON property name and each remaining CSV row becomes one object. If you disable the header option, the output is an array of arrays.

How to convert CSV to JSON online

  1. Paste CSV data or open a local .csv or .txt file up to 5 MB.
  2. Keep Auto detect for common consistent delimiters, or choose Comma, Semicolon, Tab or Pipe manually.
  3. Choose whether the first row contains column names and whether obvious numbers, booleans and null should be typed.
  4. Select Convert to JSON, review the formatted result, then copy it or download converted.json.

Example CSV converted to JSON

CSV input:

id,name,active,city
101,Ada,true,London
102,Linus,false,Helsinki

With headers enabled and type inference on, the output becomes:

[
  {
    "id": 101,
    "name": "Ada",
    "active": true,
    "city": "London"
  },
  {
    "id": 102,
    "name": "Linus",
    "active": false,
    "city": "Helsinki"
  }
]

Quoted CSV fields are parsed instead of split on every comma

Valid CSV can contain commas, quotes and line breaks inside quoted fields. A simple split(",") implementation breaks those values. This parser tracks quoted fields and escaped double quotes so a value such as "London, UK" remains one cell.

Header rows and duplicate column names

With the header option enabled, the first CSV row becomes the JSON object keys. Blank headers are renamed to predictable column_1-style names, and duplicate headers receive a numeric suffix rather than overwriting earlier values. This protects data that would otherwise disappear in a JavaScript object.

Type inference is optional

CSV itself is text. By default values stay strings, which protects identifiers such as ZIP codes, SKUs and account-like values with leading zeroes. When type inference is enabled, unambiguous numeric values, true/false and null can become native JSON values. Values such as 00123 remain strings to avoid silently removing leading zeroes.

Uneven rows are reported, not hidden

If different rows contain different numbers of columns, the converter still produces JSON but displays a warning. Missing cells are represented as empty values when headers are enabled. Review the result before feeding it into an API or production import because inconsistent rows often indicate malformed source data.

CSV vs JSON

CSV is compact and table-oriented, while JSON can represent named fields and nested structures. Converting CSV to JSON is useful when a spreadsheet export needs to be consumed by a web application, API, JavaScript workflow or configuration pipeline. The conversion does not invent nested objects because a flat CSV file does not contain enough schema information to infer them reliably.

Privacy and local file handling

The selected file is read with browser file APIs and converted locally. CSV content is not submitted to a Smart Web Utility conversion API. The 5 MB limit is an implementation guardrail to keep browser memory and UI responsiveness predictable.
