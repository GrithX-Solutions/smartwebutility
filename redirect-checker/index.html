Redirect Checker

Trace HTTP redirect chains and see every 301, 302, 303, 307 or 308 hop through to the final URL.

Result

What this tool checks

The redirect checker follows redirects one hop at a time and displays each URL, status code and Location header. Public-host validation is repeated on every hop.

When to use it

Use it during domain migrations, HTTPS changes, URL cleanup, SEO audits and debugging when a redirect chain is longer or different than expected.
