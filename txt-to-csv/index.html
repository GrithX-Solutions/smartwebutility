Convert a TXT file to CSV with the correct delimiter

A text file can hold tabular data without using the .csv extension. The important part is the delimiter between fields. This converter can read tab-delimited text, comma-delimited text, semicolon-separated values, pipe-separated rows and simple whitespace-separated columns, then write standard comma-separated CSV output.

Auto detection compares multiple non-empty lines and only selects a delimiter when the column pattern is reasonably consistent. If the source is unusual, select the delimiter manually instead of relying on a guess.

How to convert TXT to CSV online

  1. Keep TXT → CSV selected and paste the text or open a local .txt file.
  2. Use Auto detect for regular delimited data, or choose Tab, Comma, Semicolon, Pipe or Whitespace.
  3. Select Convert and review the row and column counts. Uneven rows are flagged for review rather than silently normalized.
  4. Copy the CSV result or download converted.csv.

Example: tab-delimited TXT to CSV

TXT input:

name	age	city
Ada	37	London
Linus	56	Helsinki

CSV output:

name,age,city
Ada,37,London
Linus,56,Helsinki

CSV to TXT conversion is included on the same page

Changing the direction to CSV → TXT parses comma-separated input, including quoted CSV fields, and writes a text file using the delimiter you choose. Tab-delimited output is useful for spreadsheet imports, while pipe or semicolon output can be useful when commas appear frequently inside values.

TXT vs CSV: what actually changes?

CSV is itself a text format with rules for separators and quoted values. A generic .txt file has no universal table schema. Renaming a file does not reliably convert its structure; the fields need to be parsed using the delimiter that the source actually uses. This tool performs that parsing and rewrites the rows instead of only changing the extension.

Quoted fields, blank cells and uneven rows

The CSV parser supports double-quoted fields and escaped double quotes. Blank cells are retained. The converter does not invent missing fields when one line contains fewer columns than another; it reports the range of column counts so you can decide whether the source needs cleanup.

Whitespace mode is intended for simple columns separated by spaces or tabs. It is not a fixed-width-file parser, and it cannot infer column boundaries from visual alignment when spaces are part of the values.

Privacy and local file handling

Conversion is performed by JavaScript in the browser. The selected TXT or CSV file is read locally and is not submitted to a Smart Web Utility conversion API. This implementation limits opened files to 5 MB to keep browser memory use predictable.
