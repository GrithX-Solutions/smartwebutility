Check Open Graph tags on a live page

This checker fetches the public HTML for a URL and reports the Open Graph values it finds, including the page's social title, description, URL, image, content type and site name when those tags are published.

Social title and description

Confirm the text a publisher intends social and messaging platforms to use when a URL is shared. Keep the values consistent with the visible page rather than using unrelated promotional copy.

Share URL

Review og:url when a page can be reached through multiple URL variants. It should reflect the stable public URL intended for sharing.

Preview image

Check whether an og:image value is present and points to the image you expect. Platforms can still crop, cache or reject an image based on their own rules.

Type and site name

These values give platforms additional context about the shared resource and publisher when they are supplied.

Why a platform can show different metadata

Social crawlers can cache an older version, apply their own truncation, ignore invalid image URLs or use fallback page content. This tool reports the HTML it fetched; it does not emulate every platform's crawler or cached state.

Open Graph and SEO

Open Graph metadata controls sharing presentation rather than serving as a direct Google ranking requirement. Maintain accurate HTML titles, visible content, canonicals and search metadata separately.
