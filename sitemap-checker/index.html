What an XML sitemap is for

An XML sitemap lists URLs that a site wants search engines to discover. Large sites can use sitemap index files to reference multiple child sitemaps. A sitemap helps discovery but does not guarantee crawling or indexing.

What to check

Important sitemap entries should use canonical, publicly accessible URLs and return successful responses. Avoid filling sitemaps with redirects, error pages, duplicate parameter URLs or pages that are intentionally blocked from indexing.

Sitemaps and crawlability

A URL in a sitemap still needs to be reachable through a healthy website configuration. Robots directives, authentication, canonicalization and server errors can all affect how crawlers handle a listed page.

Frequently asked questions

Do small websites need a sitemap?

Not always, but a clean sitemap is inexpensive to maintain and can make discovery and monitoring easier.

How many URLs can a sitemap contain?

Search engines publish size and URL-count limits for sitemap files. Large sites should split content into multiple sitemaps and reference them from a sitemap index.
