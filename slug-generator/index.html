About this tool

Create readable URL slugs for blog posts, products, documentation and landing pages.

Create readable lowercase URL slugs

The Slug Generator converts a title or phrase to lowercase, removes diacritics, replaces non-alphanumeric runs with your selected hyphen or underscore separator, and trims separators from the ends.

Keep URLs understandable

A short descriptive slug can help users recognize what a page is about before they open it. Remove filler that does not add meaning, but keep enough context to distinguish similar pages.

Use hyphens for normal web URLs

Hyphens are the conventional word separator for human-readable URL paths. The underscore option is included for workflows that specifically require it.

Changing a live slug changes the URL

If an indexed or linked page already has a public URL, changing its slug can break links. Update internal links and use an appropriate redirect from the old URL when a move is necessary.

Local generation

The phrase is transformed in your browser and is not uploaded to the server.

A slug is only one URL signal

Do not stuff repeated keywords into a path. A useful page still needs content that satisfies the visitor, clear navigation and consistent canonical/internal-link signals.
