How XML is converted into CSV rows

The converter looks for repeated child elements under the root and treats those elements as records. Child values are flattened into column paths, while XML attributes use an @ prefix.

Repeated records

Repeated record elements become individual CSV rows.

Nested values

Nested child elements become dotted paths so hierarchy remains understandable.

Attributes

Attributes are preserved as columns such as @id.

CSV escaping

Commas, quotes and line breaks are escaped with standard quoted-field rules.

Important limitations

CSV is tabular while XML can represent arbitrary trees, namespaces and mixed content. Complex XML cannot always be represented perfectly in flat columns.

Frequently asked questions

Does this upload my XML?

No. Conversion runs in browser JavaScript.

How are attributes represented?

Attributes use an @ prefix in generated column names.

Can every XML document become CSV?

No. Highly hierarchical or irregular XML may need a custom transformation.
