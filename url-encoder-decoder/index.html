Encode and decode URL text

Use component mode for query values, path fragments and other individual URL parts. Disable component mode when encoding or decoding a complete URL.

What URL encoding does

URL encoding, also called percent-encoding, represents characters that cannot safely appear unchanged in a URL component. A space, for example, may become %20, while reserved characters can be encoded when they need to be treated as data rather than URL syntax.

When to encode or decode a URL value

Use encoding when placing user-entered text inside a query parameter, path segment or callback value. Decode a value when you need to read the original text behind percent sequences such as %2F or %3F. Encode only the component you are inserting; encoding an entire already-structured URL can also encode separators such as :, / and ? that define the URL itself.

Query parameters

Encode parameter values containing spaces, ampersands, equals signs or non-ASCII characters so they are not confused with query-string delimiters.

Path segments

Encode data placed inside one path segment when it contains characters that would otherwise change the path structure.

Debugging

Decode copied tracking links, OAuth callback parameters or API values to see the readable data they contain.

Browser-local processing

This utility performs the conversion in your browser; the text you paste does not need to be sent to Smart Web Utility's server.

encodeURI vs encodeURIComponent

This tool's component option mirrors the distinction developers make between encodeURIComponent() and encodeURI(). Component mode encodes a value that will live inside part of a URL, including characters that would otherwise act as query or path separators. Full-URL mode preserves structural URL characters such as the scheme separator, slashes and common delimiters.

Use component mode for values

Encode a search term, callback value, filename or other piece of data before inserting it into a query parameter or path segment.

Use full URL mode carefully

When the input is already a complete URL, preserving its structural separators is usually necessary. Encoding the entire string as one component can turn those separators into data.

Percent-encoding examples

A space is commonly represented as %20, / can be represented as %2F when it is data, and ? can become %3F inside an encoded component.

Decode for debugging

Decoding makes percent-encoded query values, redirect targets and OAuth parameters easier to inspect during development.

RFC 3986 and reserved URL characters

URI syntax distinguishes reserved characters that have structural meaning from unreserved characters that can normally appear directly. Correct percent-encoding depends on where a value is placed in the URL, which is why encoding a component and encoding a complete URL are different operations.

URL encoding is not encryption

Percent-encoding makes a URL syntactically safe; it does not hide secrets. Anyone who receives the URL can decode it. Do not place passwords, API keys or other confidential values in a URL just because they are percent-encoded.
