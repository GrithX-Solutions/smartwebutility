Format and validate JSON online

Paste JSON into the input editor and choose Format JSON to produce clean, readable indentation. The validator uses the browser's native JSON parser and reports syntax errors when the input is invalid. You can also create a compact representation with Minify.

JSON Formatter

Beautifies compact JSON with 2 spaces, 4 spaces or tabs so nested objects and arrays are easier to inspect.

JSON Validator

Checks whether the input is valid JSON before formatting or minifying it, with useful error details when parsing fails.

JSON Minifier

Removes unnecessary whitespace while preserving the underlying JSON data.

Private by design

Formatting and validation run locally in JavaScript. The JSON content is not submitted to a Smart Web Utility API.

Common JSON formatting issues

JSON requires double-quoted property names and strings, does not allow trailing commas, and does not support comments. Valid values include objects, arrays, strings, numbers, booleans and null.
