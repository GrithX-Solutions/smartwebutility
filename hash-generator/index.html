Generate SHA hashes online

This tool uses your browser's Web Crypto API to calculate cryptographic digests. You can hash UTF-8 text or select a local file. File contents are read and hashed in the browser and are not uploaded to Smart Web Utility.

SHA-256

A widely used 256-bit cryptographic hash for integrity checks, APIs and security workflows.

SHA-512

A SHA-2 family hash with a 512-bit output, useful where a longer digest is preferred.

SHA-1

Included for legacy compatibility and checksum workflows. It should not be used for modern collision-resistant security designs.

Local file hashing

Select a file and generate its hash without sending the file to a server.
