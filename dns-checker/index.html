DNS record types supported

This tool supports A, AAAA, MX, TXT, CNAME, NS and CAA lookups. It is intended for quick diagnostics and validation, not as a substitute for authoritative DNS administration.

How to use DNS lookup results

DNS records control how a domain connects to websites, email services and other internet systems. An A record points a hostname to an IPv4 address, while AAAA provides the IPv6 equivalent. MX records identify mail servers, TXT records commonly carry verification or email-authentication data, and NS records identify authoritative name servers.

Common troubleshooting scenarios

If a website works from one network but not another, compare the expected A or AAAA value with the returned record. For email-delivery issues, review MX and relevant TXT records. After a DNS change, remember that recursive resolvers can continue serving cached values until their TTL expires.

Limitations

A DNS lookup shows what a resolver can currently see; it does not guarantee that every resolver worldwide has the same cached answer. For comparison across resolvers, use the DNS Propagation Checker.

Frequently asked questions

Why does DNS still show an old IP?

Cached records can remain visible until their TTL expires. Registrar, authoritative DNS and recursive resolver caches can also make changes appear at different times.

Does a correct DNS record prove the website is online?

No. DNS only maps names to records. The destination web server, TLS certificate and application must also be working.
