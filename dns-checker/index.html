DNS Checker

Check live DNS records for any domain. Supports A, AAAA, MX, TXT, CNAME, NS and CAA.

DNS result

What this DNS checker does

Enter a domain and choose a record type. The lookup is sent over HTTPS to a public recursive DNS resolver and the returned records are displayed with TTL values when available.

A / AAAA

Find IPv4 and IPv6 addresses for a hostname.

MX

See which mail servers receive email for the domain.

TXT

Inspect SPF, verification and other text-based DNS records.

NS / CNAME / CAA

Review nameservers, aliases and certificate-authority policy.

Why DNS checks matter

DNS changes, email configuration, CDN migrations and SSL validation all depend on the right records being published. A quick lookup helps confirm what a recursive resolver currently sees.

DNS record types supported

This tool supports A, AAAA, MX, TXT, CNAME, NS and CAA lookups. It is intended for quick diagnostics and validation, not as a substitute for authoritative DNS administration.
