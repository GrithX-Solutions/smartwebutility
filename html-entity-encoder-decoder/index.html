Encode HTML entities online

Encode characters such as ampersands, angle brackets, quotes and apostrophes when you need text to be represented safely as HTML source.

What HTML entity encoding is

HTML entities represent characters that have special meaning in HTML or are easier to transport in escaped form. Common examples include &lt; for a less-than sign, &gt; for a greater-than sign and &amp; for an ampersand.

When HTML entities are useful

Encoding is useful when you want literal markup characters to appear as text instead of being interpreted as HTML. Decoding converts named or numeric entities back to their readable characters for inspection, editing or data cleanup.

Show code as text

Escape characters such as < and > when a documentation page needs to display an HTML example rather than render it.

Inspect stored content

Decode entity-heavy strings copied from HTML, feeds or APIs when you need to verify the actual characters users will see.

Avoid double encoding

If already-encoded text is encoded again, &amp; can become &amp;amp;. Decode and inspect the source before applying another transformation.

Local conversion

The encoder and decoder run in your browser so ordinary pasted text does not need a network request.

Entity encoding is not a complete XSS defense

Escaping rules depend on where data is inserted: HTML text, attributes, JavaScript, CSS and URLs have different contexts. Use the output as a text-conversion utility, not as a substitute for your framework's context-aware escaping and sanitization controls.
