What DNS status, TTL and DNSSEC AD mean

DNS status is the DNS response code, separate from the HTTP status of the DNS-over-HTTPS request. NOERROR means the DNS query completed without a DNS-level error; NXDOMAIN means the queried name does not exist; SERVFAIL means the resolver could not complete the query successfully. An HTTPS request can succeed while the DNS response itself reports a failure.

TTL is the answer's time to live in seconds. Recursive resolvers can cache an answer until its remaining TTL expires, so two resolvers can temporarily return different values after a DNS change. DNSSEC AD is the authenticated-data flag exposed by the public resolver response; it indicates DNSSEC validation state for that resolver response, not a full replacement for a dedicated DNSSEC chain analysis.

Which record type should you compare?

A and AAAA

Compare IPv4 and IPv6 destinations after hosting, CDN or origin changes. Remember that a working A record does not prove the AAAA path is correct.

MX and TXT

Use MX for mail-routing destinations and TXT for SPF, ownership verification and other text-based policies. Multiple TXT answers are normal.

CNAME and NS

Use CNAME for aliases and NS for nameserver data. The report keeps returned record data visible while normalizing only for the agreement calculation.

CAA

Compare certificate-authority authorization records. The server-resolver row preserves CAA flags, tag and value instead of dropping CAA-specific fields.

Resolver comparison is not worldwide DNS propagation

This page asks a small set of named resolver paths the same question. That is useful when you specifically want to compare Google, Cloudflare and the server resolver, but it cannot prove that every ISP, enterprise resolver or country has converged. Use the DNS Checker when you want a focused lookup through one public resolver with record TTLs. Use the DNSSEC Checker when you need DS, DNSKEY and validation evidence. Use the Reverse DNS Checker for PTR and forward-confirmed reverse DNS.

Why Google and Cloudflare can disagree

Independent recursive resolvers maintain independent caches. After an authoritative change, one cache can refresh before another. Different answers can also be intentional when authoritative DNS uses geo-aware or policy-based responses. If both public resolvers return the same unexpected value, verify the authoritative zone before assuming you only need to wait.

Provider JSON methodology and limits

Google's JSON DNS-over-HTTPS API exposes DNS response status, the authenticated-data flag and answer records with TTL values. Cloudflare's JSON DNS-over-HTTPS response follows Google's schema for these fields. Cloudflare notes that DNS-over-HTTPS JSON has no formal IETF schema, so this checker treats the format as provider-documented behavior rather than a universal JSON DNS standard.

The resolver latency shown here is the time observed from the Smart Web Utility server environment for this diagnostic request. It is not a benchmark of resolver performance for your device, ISP or geographic location.

Frequently asked DNS resolver questions

Does this check whether my computer uses Google or Cloudflare DNS?

No. It sends the hostname you enter directly to the public resolver APIs from Smart Web Utility. It does not inspect or change the DNS resolver configured on your device or router.

Why can Google and Cloudflare return different answers?

They use independent recursive caches, so cache age can differ after a DNS change. Authoritative DNS can also intentionally vary answers by resolver location or policy.

Does NOERROR always mean the record exists?

No. A DNS response can be NOERROR while the requested record type has no answer. Read the requested-type answer list together with the status.

Does DNSSEC AD mean my entire DNSSEC setup is correct?

It is useful resolver evidence, but this page is not a full DNSSEC chain validator. Use the DNSSEC Checker when you need dedicated DS, DNSKEY and validation diagnostics.

Should I use this page to check global DNS propagation?

No. Use the homepage worldwide checker for distributed country-level probes. This page intentionally compares named resolver paths.
