YAML to JSON Converter

Paste YAML or open a local .yaml/.yml file and convert it to formatted JSON. The converter handles a single YAML document or turns a multi-document stream into one JSON array.

Convert YAML to JSON without uploading your data

This converter parses YAML with js-yaml 4.1.0 and serializes the resulting data as standard JSON. Choose 2- or 4-space indentation, then copy the output or download a .json file. The conversion runs in browser JavaScript; Smart Web Utility does not send your YAML to a conversion API.

Mappings and sequences

YAML mappings become JSON objects, while YAML sequences become JSON arrays. Nested structure remains nested instead of being flattened.

Typed scalar values

Parsed numbers, booleans and null values become their JSON equivalents. Strings remain strings after the YAML parser resolves them.

Configurable JSON indentation

Use 2 spaces for compact readable output or 4 spaces when that matches your repository or review convention.

Parser-backed validation

The converter stops on malformed YAML and shows the parser message. When the parser supplies a line and column, the error message keeps that location.

Multi-document YAML becomes a JSON array

A YAML stream can contain several documents separated with ---. JSON has no equivalent document-stream syntax, so this tool converts one YAML document to one JSON value and converts two or more documents to a top-level JSON array in document order. That behavior makes deployment bundles and multi-resource configuration files easier to inspect without silently dropping later documents.

What changes during YAML to JSON conversion

JSON cannot preserve YAML comments, anchors, aliases, presentation style or every YAML-specific tag as source text. The parser resolves the YAML into data first, and JSON represents that resulting data. If you must preserve comments or exact YAML authoring structure, keep the original file and use a source-aware YAML editor instead of replacing it with converted JSON.

YAML mapping keys and application schemas

JSON object property names are strings, while YAML can express more flexible mapping keys. A successful parse does not prove that the generated JSON matches your application's schema, OpenAPI document, Kubernetes resource, CI configuration or other domain rules. Validate the converted output with the receiving system when schema correctness matters.

Local file handling and privacy

The file picker accepts YAML files up to 5 MB and reads them with browser file APIs. Conversion happens on the page. The page loads the js-yaml library from jsDelivr, but the YAML text itself is not submitted to Smart Web Utility for conversion. Remove secrets before sharing screenshots, copied output or downloaded files.

Frequently asked questions

Does YAML to JSON preserve comments?

No. The YAML parser resolves data values, and JSON has no comment syntax.

What happens to multiple YAML documents?

One document becomes one JSON value. Two or more YAML documents become a top-level JSON array in the same order.

Can this parse YAML arrays?

Yes. YAML sequences become JSON arrays, including nested sequences.

Can I use 4-space JSON indentation?

Yes. Choose 4 spaces from the Indent control before converting.

Is my YAML uploaded to Smart Web Utility?

No. The conversion runs in browser JavaScript.
