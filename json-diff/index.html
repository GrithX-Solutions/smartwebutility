Semantic JSON comparison

This tool parses both inputs and compares their values and keys, so whitespace and object-key order do not create false differences.

Added values

The diff marks paths that exist only in the right JSON as added.

Removed values

The diff marks paths that exist only in the left JSON as removed.

Changed values

Changed values show both left and right representations.

Array order

Optionally ignore array order when sequence is not meaningful.

Compare pasted JSON or local JSON files

Paste either document or load a local .json file into each side. Files up to 5 MB are read with browser APIs and stay on your device. Use Swap sides when you need to reverse the baseline and modified document without copying the payloads again.

Download a structured JSON diff report

After a successful comparison, download a machine-readable report containing the comparison mode, summary counts and each changed JSON path. Every row records whether the path was added, removed or changed and whether a left or right value exists, so missing values are not confused with JSON null.

Array comparison caveat

Ignoring array order normalizes and sorts values by JSON representation. That is useful for many configuration comparisons but is not a domain-specific set matcher. Arrays that contain duplicate objects, values with different data types, or records whose identity depends on one field may need application-specific comparison rules.

How object keys and value types are compared

The comparison ignores object-key order because it compares JSON objects by key and value rather than source order. Value types still matter: the number 1, the string "1", the boolean true and the string "true" are different JSON values.

Useful JSON diff workflows

A semantic diff is useful when comparing API responses, deployment configuration, feature flags, application settings, test fixtures or generated JSON where whitespace and key ordering can change without changing meaning. Path-based output identifies the exact nested field that the right side added, removed or changed.

What this tool does not do

This tool does not apply a JSON Schema, understand business rules, identify records by a custom primary key, merge two documents or decide which side is correct. It reports structural and value differences between two valid JSON inputs. The parser rejects invalid JSON so the diff does not misrepresent a parse error as a data difference.

Privacy and local comparison

Browser JavaScript parses and compares both JSON inputs. Smart Web Utility does not send the comparison content to an API. You should still remove secrets before sharing screenshots, copied diff output or example payloads with other people.

Frequently asked questions

Does key order affect the result?

No. The comparison normalizes object keys before equality checks.

Can I ignore array order?

Yes, using the checkbox above.

Can I compare local JSON files?

Yes. Load one file on each side, up to 5 MB per file. The browser reads them locally.

Can I download the differences?

Yes. After comparing, download a structured JSON report with summary counts and path-level added, removed and changed values.

Is my JSON uploaded?

No. Parsing, file reading and comparison run locally in browser JavaScript.
