Semantic JSON comparison

This tool parses both inputs and compares their values and keys, so whitespace and object-key order do not create false differences.

Added values

Paths only in the right JSON are marked added.

Removed values

Paths only in the left JSON are marked removed.

Changed values

Changed values show both left and right representations.

Array order

Optionally ignore array order when sequence is not meaningful.

Array comparison caveat

Ignoring array order normalizes and sorts values by JSON representation. That is useful for many configuration comparisons but is not a domain-specific set matcher.

Frequently asked questions

Does key order affect the result?

No. Object keys are normalized before equality checks.

Can I ignore array order?

Yes, using the checkbox above.

Is my JSON uploaded?

No. Parsing and comparison run locally in browser JavaScript.
