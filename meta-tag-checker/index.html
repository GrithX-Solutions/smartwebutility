SEO Meta Tag Checker

Check the live HTML a public URL returns after safe redirects. Review its title, meta description, canonical, robots and Googlebot directives, HTTP X-Robots-Tag, language, viewport and H1 context in one report.

Result

Inspect the SEO metadata returned by a live page

The Meta Tag Checker fetches a public URL, follows up to three redirects with each destination revalidated, then parses the returned HTML. The report shows the final URL, HTTP status, title, meta description, canonical link, robots and Googlebot directives, HTTP X-Robots-Tag, HTML language, viewport, H1 context and duplicate tag counts.

Title and description

Confirm the intended values appear in the HTML head and check whether a template accidentally produced duplicates. Character counts provide editing context, not fixed pass-or-fail SEO limits.

Robots and Googlebot

Review general robots directives and Googlebot-specific directives together. The report also checks the HTTP X-Robots-Tag header and flags a directly observed noindex.

Canonical declaration

See the canonical URL declared by the HTML and whether multiple canonical links appear. Use the dedicated Canonical Tag Checker when you need target status, redirect, placement, noindex-conflict or canonical-chain diagnostics.

Final URL and page context

See where redirects finish before metadata is parsed, then review the HTML lang, viewport, H1 count and first H1 as supporting page context.

How to interpret title, description and indexing directives

Title should describe the page clearly and match its visible content. Google does not publish a fixed title character limit; search results truncate title links to fit the device width and can generate a different title link when page signals disagree. Meta descriptions can supply snippet text, but Google can instead select a passage from the page that better matches the query. Treat the character counts here as editorial context rather than a ranking score.

Robots, Googlebot and X-Robots-Tag can control indexing and search-result presentation. An unintended noindex deserves immediate review, but this checker only reports directives it can directly observe in the fetched response. It does not claim that a URL is indexed or indexable in Google.

Why redirects and duplicate tags matter

A metadata check should reflect the page users and crawlers actually reach. This tool therefore reports both the requested URL and final URL after a bounded redirect path. It also counts title, description, robots, Googlebot and canonical elements so template duplication is visible instead of silently returning only the first value.

What this checker deliberately leaves to specialist tools

This tool parses server-returned HTML and headers; it does not render JavaScript-injected metadata or query a search engine's index. It reports the declared canonical but leaves canonical target health, placement conflicts and chains to the Canonical Tag Checker. It also leaves og:* social metadata to the Open Graph Checker. For JavaScript-heavy pages, compare the response with rendered-page inspection and Google Search Console.

Useful checks after a site change

Template deployment

Check representative pages after a CMS or theme release to catch missing or duplicated metadata before the issue affects a large section of the site.

Domain or URL migration

Confirm canonicals point at the intended new URLs and that migrated pages are not accidentally carrying staging or legacy metadata.

Indexing investigation

Look for an unexpected HTML robots directive, then continue with robots.txt, response headers, canonicalization and Search Console when deeper diagnosis is needed.

Content refresh

Verify title and description changes are actually present in the public HTML served to the checker.

Frequently asked meta tag questions

Does a meta description guarantee the snippet shown in search?

No. It provides useful descriptive metadata, but search engines can choose text from the page when they believe it better answers a user's query.

Should every page have a canonical tag?

A self-referencing canonical is commonly used on indexable pages, especially when the same content can be reached through multiple URL variations. The canonical should reflect the site's real preferred URL strategy.

Is more than one H1 automatically an SEO error?

No. Heading structure should make the page understandable. This checker reports the count as a diagnostic signal rather than enforcing a rigid one-H1 rule.

Is there a fixed SEO character limit for titles or meta descriptions?

No fixed character count guarantees how Google will display a title link or snippet. Search results vary by device and query, and Google can generate different text. Use the reported counts as editing context rather than a hard SEO score.

Why might this tool miss metadata?

The checker reads the server response after bounded redirects. A rendered application can still inject or replace metadata after the initial HTML loads, so use browser inspection and Search Console for deeper diagnosis.
