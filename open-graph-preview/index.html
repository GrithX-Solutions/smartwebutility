Preview Open Graph metadata

Open Graph tags help social platforms understand the title, description, canonical page URL and preview image you want associated with a shared link. Actual rendering varies by platform.

Preview Open Graph metadata before publishing

Open Graph metadata gives social and messaging platforms a preferred title, description and image when a URL is shared. This preview helps you compose the core values and see an approximate card layout before adding the tags to a page.

What to review in a social preview

Open Graph title

Use a concise title that still makes sense when someone sees the card without the surrounding page context.

Description

Summarize the useful reason to open the page. Avoid repeating the title word-for-word or filling the field with keywords.

Canonical share URL

Use the stable public URL you want people to visit rather than a temporary preview, tracking or staging address.

Image choice

Choose an image that remains understandable after cropping. Platforms can use different card ratios and may cache an older image.

The preview is an approximation

Facebook, LinkedIn, Slack, Discord and other platforms can apply their own layouts, truncation rules, image crops and caching. A visually correct preview here does not guarantee an identical card everywhere. After publishing, use the platform's own debugging or refresh tool when you need to confirm what its crawler actually fetched.

Open Graph is not a direct ranking signal

These tags primarily control sharing presentation. They can improve consistency when links are shared, but they should not replace accurate visible page content, a descriptive HTML title, canonicalization or normal search metadata.
