Morse Code Translator with Sound

Translate text into International Morse code or decode pasted Morse back to text. Play the Morse sequence as real browser-generated audio with adjustable words per minute and tone frequency.

Translate text to Morse code and Morse code back to text

This translator supports the Latin alphabet A–Z, digits 0–9 and common International Morse punctuation. Text-to-Morse mode converts letters into dots and dashes, separates letters with spaces and separates words with a slash. Morse-to-text mode accepts dots and dashes, slash-separated words and common typographic dot/dash characters.

How to use the Morse code translator

  1. Select Text → Morse or Morse → Text.
  2. Paste or type the source message.
  3. Select Translate to generate the result.
  4. For Morse audio, choose a playback speed and tone frequency, then select Play sound.

Morse code example

Text: SOS HELP

Morse:

... --- ... / .... . .-.. .--.

The slash marks a word boundary. Individual Morse letters are separated by spaces.

How the Morse sound timing works

The player follows standard relative Morse timing: a dot lasts one timing unit, a dash lasts three units, the gap inside one Morse character is one unit, the gap between letters is three units, and the gap between words is seven units. Playback speed uses the common PARIS timing relationship, where one unit is approximately 1200 / WPM milliseconds.

The tone is generated with the browser Web Audio API rather than a prerecorded sound file. You can adjust the tone frequency from 300 Hz to 1000 Hz and playback speed from 5 to 40 WPM. Audio playback is limited to 120 seconds per run so a large pasted message does not schedule an excessive amount of browser audio.

Supported Morse characters

The translator includes A–Z, 0–9 and common punctuation such as period, comma, question mark, apostrophe, exclamation mark, slash, parentheses, ampersand, colon, semicolon, equals, plus, hyphen, underscore, quotation mark, dollar sign and @. Unsupported text characters are reported instead of silently being deleted.

Morse input formats

For Morse-to-text conversion, use spaces between encoded letters. Separate words with / or a long multi-space gap. The parser also normalizes common typographic dot and dash characters such as · and an en/em dash to ordinary Morse . and - before decoding.

This page generates Morse sound; it does not decode microphone or audio files

The audio feature plays the Morse sequence that is already present as text or generated from text. It does not listen to a microphone, upload an MP3/WAV file, identify tones from recordings or claim to decode noisy Morse audio. Audio decoding is a different signal-processing task and is intentionally outside this page's capabilities.

Text to Morse vs Morse to English

International Morse encodes characters rather than translating language meaning. In Morse → Text mode, the page converts Morse character sequences into Latin letters, numbers and supported punctuation. It does not translate the decoded words between human languages.

Privacy

Translation and audio scheduling run in browser JavaScript. The message is not submitted to a Smart Web Utility translation or audio API. Sound is generated locally through Web Audio after you press the playback button.
