Escape text for a JSON string

JSON strings use backslash escape sequences for characters that would otherwise terminate the string or represent control characters. The Escape action uses the browser's JSON serializer so quotation marks, backslashes, tabs, carriage returns, line feeds and other required control characters are encoded according to JSON rules.

Quotes and backslashes

Double quotes become \" and backslashes become \\, allowing the text to be placed safely inside a JSON string value.

Tabs and line breaks

Tabs, new lines and carriage returns become \t, \n and \r rather than literal control characters inside the escaped output.

Optional JSON quotes

Enable surrounding quotes when you need a complete JSON string literal. Leave it disabled when another application expects only the escaped string content.

Forward slashes

JSON does not require forward slashes to be escaped, but the optional slash setting can emit \/ for systems that prefer that representation.

Unescape JSON string content

The Unescape action accepts either a complete quoted JSON string or raw escaped string content. It decodes valid JSON escapes such as \b, \f, \n, \r, \t, escaped quotes, escaped backslashes and \uXXXX Unicode sequences.

Escaping is not the same as formatting JSON

This tool operates on a single JSON string value. It does not beautify objects, validate object structure or repair malformed JSON documents. Use the JSON Formatter when your input is an object or array and you need structural validation, indentation or minification.

Unicode behavior

Valid JSON can contain ordinary Unicode characters directly, so the Escape action does not convert every non-ASCII character into a \uXXXX sequence. Required control characters are escaped, while readable Unicode text generally remains readable.

Common developer use cases

JSON escaping is useful when embedding text into API payloads, test fixtures, configuration values, logs, generated source code or nested JSON strings. Unescaping is useful when reading copied log output, serialized message content or API fields that contain escaped string data.

Privacy

Escaping and unescaping run locally in browser JavaScript. Input text is not submitted to a Smart Web Utility API for this operation.

Frequently asked questions

What does JSON escape do?

It converts characters that need special representation inside a JSON string into valid JSON escape sequences.

Can I unescape a quoted JSON string?

Yes. A valid quoted JSON string can be parsed directly, and raw escaped content is also accepted.

Are forward slashes required to be escaped?

No. Escaping / as \/ is optional in JSON.

Does this validate a complete JSON object?

No. Use the JSON Formatter for objects and arrays.
