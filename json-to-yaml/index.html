Convert JSON to YAML locally in your browser

This converter parses valid JSON and serializes the resulting objects, arrays and scalar values as YAML with js-yaml 4.1.0. Choose the indentation you want, then copy the YAML or download it as a .yaml file. Smart Web Utility does not send the JSON content to a conversion API.

Objects become mappings

JSON objects become YAML key-value mappings while nested objects keep their hierarchy.

Arrays become sequences

JSON arrays become YAML sequences and retain their item order.

Data types stay data types

Numbers, booleans, strings and null values remain typed values instead of being forced into text.

Choose the indentation

Generate YAML with 2 or 4 spaces to match the style used by your repository, configuration files or review workflow.

JSON must be valid before conversion

The converter uses the browser's JSON parser before it generates YAML. JSON does not allow comments, trailing commas, unquoted keys or single-quoted strings. If the input is invalid, the page reports the parse error instead of guessing how to repair the document. Use the JSON Formatter first when you need to validate or inspect malformed JSON.

What JSON cannot add to YAML

JSON has no comments, anchors, aliases, custom YAML tags or source-level YAML formatting choices. A JSON-to-YAML conversion therefore creates a clean data representation; it cannot invent comments or reconstruct YAML authoring details that were never present in the JSON input.

Strings, numbers and ambiguous-looking values

The serializer quotes values when needed so YAML readers can distinguish strings from booleans, numbers, null values or syntax. That matters for values such as version identifiers, numeric-looking strings and text that contains punctuation. Always validate the generated YAML against the application that will consume it when schema rules matter.

Local file handling and privacy

The file picker accepts JSON files up to 5 MB and reads them with browser file APIs. Conversion runs on the page. The page loads the js-yaml library from jsDelivr, but your pasted or selected JSON is not submitted to Smart Web Utility for conversion.

Frequently asked questions

Will JSON arrays stay arrays in YAML?

Yes. JSON arrays become YAML sequences in the same order.

Can I choose 4-space YAML indentation?

Yes. Choose 4 spaces from the Indent control before converting.

Does converting JSON to YAML preserve comments?

No. JSON has no comment syntax, so there are no source comments to carry into YAML.

Does this validate an OpenAPI or Kubernetes schema?

No. It validates JSON syntax and converts data format only. Use the receiving tool or a schema validator for domain-specific rules.

Can I download the result?

Yes. The Download button saves the output as a .yaml file.
