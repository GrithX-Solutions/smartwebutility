Convert XML to an Excel XLSX workbook

This XML to Excel converter turns repeated XML records into worksheet rows. It finds a repeated complex element, flattens child values into columns, includes XML attributes with an @ prefix, shows a tabular preview, and then generates an actual .xlsx workbook for download.

The XLSX export uses the browser build of SheetJS Community Edition. Your XML content is parsed on the page and is not posted to a Smart Web Utility conversion API. The spreadsheet library itself is loaded from SheetJS's pinned public CDN version.

How to convert XML to Excel online

  1. Paste XML into the editor or open a local .xml file up to 5 MB.
  2. Select Convert XML. The tool searches for repeated complex elements that can represent spreadsheet rows.
  3. Review the detected row count, column count, record element and tab-separated preview.
  4. Select Download .xlsx to create an Excel workbook named xml-to-excel.xlsx.

Example XML records mapped to Excel columns

XML input:

<catalog>
  <product sku="A-100">
    <name>Keyboard</name>
    <price>79.99</price>
  </product>
  <product sku="B-200">
    <name>Mouse</name>
    <price>39.50</price>
  </product>
</catalog>

The detected <product> elements become two rows. Columns include @sku, name and price.

How nested XML is flattened

A single nested object is flattened with dot-separated paths, such as address.city. Repeated leaf elements are joined in one cell with a separator so their values are not silently overwritten. Repeated complex child structures are preserved as JSON text inside a cell because a generic converter cannot safely invent multiple spreadsheet tables without knowing the XML schema.

XML attributes and data types

Attributes are written as columns beginning with @, for example @id or @sku. By default all scalar values remain text. This protects identifiers such as ZIP codes, account-like values or product codes from accidental numeric conversion. Enable Infer numbers & booleans only when the XML values are meant to become spreadsheet number or boolean cells.

XML to Excel limitations

XML can represent trees, mixed content, namespaces, schemas and nested collections that do not map perfectly to one flat worksheet. The automatic record detector is designed for common repeated-record XML such as catalogs, exports and API datasets. Schema-driven XML, deeply nested collections or mixed-content documents may need a custom transformation.

This page does not apply an XSD, infer dates, evaluate entity definitions or create multiple related worksheets. Review the preview before using the workbook in a production import.

Why convert XML instead of only opening it in Excel?

Desktop spreadsheet applications can import some XML directly, but behavior depends on the XML shape, mappings and application version. A browser converter is useful when you want a quick flat table, need an XLSX file without changing the source, or want to inspect how repeated records and nested values map before sharing the data.
