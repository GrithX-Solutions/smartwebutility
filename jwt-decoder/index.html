Decode a JWT online

A JSON Web Token typically contains three Base64URL-encoded sections separated by dots: the header, payload and signature. This tool decodes the first two sections into readable JSON and highlights standard claims such as issuer, subject, audience, expiration and issue time.

Header

Inspect metadata such as the signing algorithm and token type.

Payload

Read custom and standard claims stored inside the JWT payload.

Time claims

Convert exp, iat and nbf Unix timestamps to readable ISO dates.

Important limitation

Decoding a JWT does not prove it is authentic. Signature verification requires the correct secret or public key and expected algorithm.
