Convert HTML structure into JSON

HTML and JSON describe information in different ways, so “HTML to JSON” can mean more than one thing. This tool makes the output model explicit. DOM tree mode serializes HTML structure, while table mode extracts tabular data into JSON rows.

DOM tree mode

Each HTML element becomes a JSON object with a lowercase tag, an attributes object when attributes exist, and a children array for nested elements, text nodes and optional comments.

Table extraction mode

Each HTML table becomes a JSON object containing rows. With the header option enabled, the first row becomes object keys; otherwise every row is returned as an array of cell text values.

Text and comments

Non-empty text nodes are preserved in DOM tree mode. Whitespace-only text and comments are excluded by default to keep JSON compact, but both behaviors can be changed with the options above.

Attributes stay explicit

HTML attributes are written into an attributes object instead of being mixed with child content, which keeps element metadata separate from text and nested elements.

What the DOM tree JSON looks like

An element such as <p data-id="42">Hello</p> becomes a JSON object with tag: "p", attributes: {"data-id":"42"}, and a child text node containing Hello. This representation is descriptive rather than a browser DOM API snapshot, so it avoids implementation-specific properties that are not useful for portable JSON.

HTML fragments and browser parsing

The browser parses input with its built-in HTML parser. A fragment can therefore be wrapped into an implied document structure such as html, head and body, and malformed HTML can be repaired according to browser parsing rules. The output represents the parsed DOM, not a byte-for-byte copy of the source.

Scripts are not executed during conversion

HTML is parsed with DOMParser; embedded scripts are represented as inert parsed elements and are not inserted into the live page. The converter does not fetch linked resources or execute source JavaScript as part of the transformation.

HTML table to JSON behavior

Table mode reads rows and cell text from th and td elements. When the first row is used as a header, blank names receive generated Column N labels and duplicate names receive suffixes so one value does not overwrite another. Complex rowspan and colspan layout is not expanded into a spreadsheet-style grid.

What this converter does not infer

It does not guess application-specific schemas, scrape remote URLs, execute JavaScript to render dynamic content, infer microdata semantics, or turn arbitrary visual layout into business objects. If an application expects a particular JSON contract, transform this neutral output into that contract explicitly.

Frequently asked questions

Can I convert an HTML file to JSON online?

Yes. Open a local HTML file up to 5 MB or paste HTML source, then convert it in the browser.

Does it convert HTML tables to JSON?

Yes. Choose HTML tables mode to extract table rows into JSON arrays or header-keyed objects.

Are scripts executed?

No. The input is parsed as inert HTML and is not inserted into the live page for execution.

Does malformed HTML cause an error?

Not necessarily. Browser HTML parsers repair many malformed structures, so the JSON reflects the parsed DOM.

Is the HTML uploaded?

No. Conversion runs locally in browser JavaScript.
