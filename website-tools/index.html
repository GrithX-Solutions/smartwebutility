Website diagnostics guide

Free website tools for performance, DNS, SSL and HTTP checks

Website troubleshooting usually crosses several layers. A slow page can be a front-end performance problem, a redirect chain can add latency before rendering begins, a certificate issue can break HTTPS, and DNS can point users to the wrong host before the application is reached. This hub groups those checks so you can move from symptom to evidence.

Website speed and Core Web Vitals

Start with the mobile or desktop Lighthouse test when the problem is loading speed, rendering, script cost, image weight or other performance diagnostics.

DNS and DNSSEC

Use DNS lookup and propagation tools for A, AAAA, MX, TXT, CNAME, NS and CAA records, then inspect DNSSEC when signed DNS integrity matters.

SSL and HTTPS

Check certificate validity, issuer, hostname coverage and expiry when browsers show TLS warnings or a deployment has recently changed certificates.

HTTP status, headers and caching

Inspect response codes, security headers and Cache-Control behavior to diagnose server responses, browser/CDN caching and policy configuration.

Redirect chains

Trace 301, 302, 307 and 308 hops to find loops, unnecessary intermediate URLs and unexpected final destinations.

Favicons and site metadata

Generate browser and app icons, then use metadata and Open Graph tools to verify how a public page describes itself to browsers, search systems and social platforms.

Move from website diagnostics to SEO evidence

When the issue is broader than one protocol or response, use the free SEO audit tools to review crawlability, canonicals, metadata, structured data and internal linking across multiple pages.

Fast by default

Pages use lightweight HTML, CSS and focused JavaScript instead of a large framework runtime.

Privacy-minded

Browser-side processing is preferred whenever the task does not require a network request.

Built for practical search intent

Each tool has a dedicated crawlable URL and focused content around a specific task.
