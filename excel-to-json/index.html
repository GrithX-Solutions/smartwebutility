Excel to JSON Converter

Open an Excel workbook, choose the worksheet, and convert rows to formatted JSON without uploading the file. Use the first row as object keys or export each worksheet row as a JSON array.

Convert Excel XLS or XLSX files to JSON

This Excel to JSON converter reads the workbook directly in your browser and turns the selected worksheet into formatted JSON. It supports both legacy .xls files and modern .xlsx workbooks through the pinned SheetJS Community Edition browser build already used by the site's Excel export tools.

How to convert Excel to JSON online

  1. Open a local .xls or .xlsx workbook up to 5 MB.
  2. Select the worksheet you want to convert.
  3. Keep First row is header enabled to create JSON objects, or disable it to export rows as arrays.
  4. Review the formatted JSON, then copy it or download excel-to-json.json.

Example worksheet to JSON objects

If an Excel sheet contains these rows:

id | name  | active
101| Ada   | TRUE
102| Linus | FALSE

With the first row used as headers, the output follows this structure:

[
  {
    "id": 101,
    "name": "Ada",
    "active": true
  },
  {
    "id": 102,
    "name": "Linus",
    "active": false
  }
]

Worksheet selection matters

Excel workbooks can contain multiple sheets with different schemas. After the file is opened, the converter lists the workbook's sheet names and converts only the selected worksheet. Changing the selection regenerates the JSON instead of silently combining unrelated tables.

Header rows and duplicate columns

When headers are enabled, values from the first row become JSON property names. Blank header cells receive predictable column_1-style names, and duplicate names receive numeric suffixes so one column does not overwrite another. If headers are disabled, each worksheet row becomes a JSON array in the original column order.

Excel numbers, booleans and dates

Workbook values are read using their stored cell values. Numeric and boolean cells remain native JSON numbers and booleans. Date cells that are recognized by the workbook parser are serialized to ISO date-time strings. Formulas are not recalculated by this browser tool; the conversion uses the value stored in the workbook.

Blank cells, merged cells and complex spreadsheets

Blank cells are retained as empty values where needed. Merged regions, hidden rows, charts, formatting, comments and workbook macros are not represented in JSON because JSON output describes the worksheet data rather than Excel presentation features. A workbook that uses formulas or visual layout as its primary structure may need a custom export rather than a generic row converter.

Excel to JSON vs CSV to JSON

Use this page when the source is an actual Excel workbook and you need sheet selection or native workbook values. If the source is already a text CSV file, the CSV to JSON converter is lighter and provides delimiter controls that are not relevant to XLS/XLSX files.

Privacy and local file handling

The selected workbook is read locally with browser APIs and is not uploaded to a Smart Web Utility conversion endpoint. The workbook parser is loaded from the pinned SheetJS CDN dependency documented in the repository. The CDN receives the normal script request metadata, but the tool does not send your workbook contents to that CDN.
