Hex to ASCII Converter

Convert hexadecimal byte values into readable ASCII or UTF-8 text, or encode text back to hexadecimal. Invalid bytes and unsupported characters are reported instead of being silently discarded.

Convert hex bytes to ASCII text

This converter turns hexadecimal byte values into text. In strict ASCII mode, each byte must be between 00 and 7F. Printable ASCII characters are shown directly, tab/newline/carriage-return bytes are preserved, and other control bytes are displayed as visible \xNN escapes so invisible data is not silently lost.

How to convert hex to ASCII online

  1. Keep Hex → Text selected.
  2. Paste continuous hex such as 48656C6C6F, or spaced/prefixed bytes such as 0x48 0x65 0x6C 0x6C 0x6F.
  3. Use ASCII for 7-bit text or UTF-8 when the bytes represent UTF-8 characters.
  4. Select Convert and copy the decoded text.

Hex to ASCII example

Hex:

48 65 6C 6C 6F 20 57 6F 72 6C 64

ASCII text:

Hello World

Convert ASCII or UTF-8 text back to hexadecimal

Switch to Text → Hex to encode text into byte values. ASCII mode rejects characters outside the 7-bit ASCII range rather than truncating them. UTF-8 mode uses the browser's UTF-8 encoder, so characters such as accented letters and non-Latin scripts can be represented as their UTF-8 byte sequences.

Hex input formats supported

You can paste continuous hexadecimal digits or separate bytes with spaces, commas, colons, semicolons, underscores or hyphens. Optional 0x prefixes are accepted. Every byte still requires two hexadecimal digits; odd-length input and non-hexadecimal tokens return an error instead of being guessed.

ASCII is not the same as UTF-8

ASCII defines 128 values from 0 through 127. UTF-8 is a variable-length encoding that preserves ASCII byte values for the first 128 characters while representing many more Unicode characters with multi-byte sequences. If a hex stream contains bytes above 7F, strict ASCII mode reports them. Switch to UTF-8 only when the source bytes are actually UTF-8 encoded.

What about endianness?

For ordinary text byte streams, this converter processes bytes in the order they appear. Endianness is mainly relevant when interpreting multi-byte numeric values or encodings such as UTF-16. Reversing byte order is not appropriate for a normal sequence of ASCII or UTF-8 bytes, so this tool does not silently reorder them.

Control characters

ASCII includes control values in addition to printable characters. Tab (09), line feed (0A) and carriage return (0D) are kept as their corresponding whitespace. Other non-printable 7-bit control bytes are rendered as \xNN escapes so you can still see where they occur.

Privacy

All parsing, ASCII validation and UTF-8 encoding/decoding happen in browser JavaScript. The input is not sent to a Smart Web Utility conversion API.
