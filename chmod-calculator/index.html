Calculate chmod octal and symbolic permissions

Unix-style permission modes use three ordinary permission groups: owner, group and others. Each group has read, write and execute/search bits with octal values 4, 2 and 1. Adding the selected values produces one octal digit per class—for example, rwx is 7 and r-x is 5.

Owner permissions

The owner or user class is represented by u. Read contributes 4, write contributes 2 and execute/search contributes 1.

Group permissions

The group class is represented by g and uses the same 4/2/1 calculation independently from the owner bits.

Other permissions

The other class is represented by o and controls users who are neither the file owner nor members of the file's group for the permission check.

Special mode bits

A leading octal digit can represent setuid (4), setgid (2) and the sticky/restricted-deletion bit (1), producing modes such as 4755, 2755 or 1777.

What chmod 755 means

755 means the owner has read, write and execute permissions (rwx), while group and others have read and execute permissions (r-x). The symbolic nine-character form is rwxr-xr-x.

What chmod 644 means

644 maps to rw-r--r--: the owner can read and write, while group and others can read. It is common for ordinary non-executable files, but the correct mode always depends on the application, web server, deployment process and security requirements.

setuid, setgid and sticky bit

GNU's documented numeric layout assigns 4000 to setuid, 2000 to setgid and 1000 to the sticky/restricted-deletion flag. Their real effects depend on the object type, operating system, filesystem and execution context. Special letters in symbolic ls-style output

When setuid or setgid is present, the execute position can display s or S depending on whether execute is also enabled. The sticky bit can display t or T in the others execute position. The calculator shows this ls-style representation separately from the basic nine-character rwx input.

This calculator does not change files

The generated command is text only. Running chmod changes mode bits on the target system and can be affected by ownership, privileges, filesystem behavior and platform-specific rules. Frequently asked questions

How do I calculate chmod permissions?

Add read=4, write=2 and execute=1 for owner, group and others, then place the three octal digits together.

What does chmod 755 mean?

It is rwxr-xr-x: full owner permissions and read/execute permissions for group and others.

Does the calculator support 4-digit chmod modes?

Yes. The leading digit represents setuid, setgid and sticky bits.

Can I paste rwxr-xr-x?

Yes. Enter a nine-character symbolic permission string and apply it to update the checkboxes and octal mode.

Does this tool run chmod on my files?

No. It only calculates permission representations and generates command text in your browser.
