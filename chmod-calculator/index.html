Linux permissions calculator: octal, rwx and chmod commands

Linux and other Unix-like systems represent the basic permission set with three classes: owner (user), group and others. Each class has read, write and execute bits. This calculator keeps the checkboxes, octal value and symbolic rwx string synchronized so you can work from whichever representation you already have.

Read = 4

The read bit contributes 4 to a class digit. For a regular file it permits reading file contents; for a directory it permits reading directory entries, subject to other permission requirements.

Write = 2

The write bit contributes 2. On regular files it permits modifying contents; on directories it participates in creating, deleting or renaming entries when the other required permissions are present.

Execute = 1

The execute bit contributes 1. For executable files it permits execution; for directories it controls traversal/search access.

Digits are sums

7 means read + write + execute (4+2+1), 6 means read + write, and 5 means read + execute. A mode such as 755 applies those sums to owner, group and others in order.

What chmod 755 and chmod 644 mean

755 is rwxr-xr-x: the owner can read, write and execute, while group and others can read and execute. 644 is rw-r--r--: the owner can read and write while group and others are read-only. These are common examples, not universal recommendations; the correct permission depends on whether the target is a file or directory and what the application must allow.

Paste permissions directly from ls -l

The symbolic field accepts either the nine permission characters or the usual 10-character permission field copied from ls -l. For example, -rwsr-xr-x becomes mode 4755, while drwxrwxrwt becomes 1777. The first character only describes the file type, so the calculator ignores it when computing chmod bits and returns the normalized nine-character permission string.

Special permission bits: setuid, setgid and sticky

A leading octal digit represents three special bits. Setuid contributes 4, setgid contributes 2 and sticky contributes 1. Symbolic permission output uses s or S for setuid/setgid and t or T for sticky depending on whether the corresponding execute bit is set. This is why 4755, 2755 and 1777 have four digits. Their runtime effect depends on file type, operating system and filesystem semantics, so apply them deliberately.

Generate octal and symbolic chmod commands

Enter a target path and optionally enable recursive mode to generate two equivalent assignment commands. The octal form uses a mode such as chmod 4755 file. The symbolic assignment form expresses the same final bits by class, such as chmod u=rwxs,g=rx,o=rx file. Unlike an ls -l display string, chmod symbolic syntax uses clauses such as u=, g= and o=; the calculator includes s or t when the matching special bit is selected.

Recursive changes can affect many files and directories at once. A single recursive mode can also make regular files executable when you only intended to add directory search permission, so review the target tree and permission model before using -R in production.

umask calculator

A process umask removes permission bits from base creation modes. New regular files commonly start from base 666 and directories from 777 before the mask is applied. Use the field below to calculate the resulting basic modes.

Security note about 777

777 gives read, write and execute permission to owner, group and others. It can be appropriate in narrow controlled cases, but using it as a generic fix can grant more access than intended. Prefer the least permissions needed by the actual user, group and service model.

Frequently asked questions

What is chmod 755?

It represents rwxr-xr-x: owner has read/write/execute, while group and others have read/execute.

What is chmod 644?

It represents rw-r--r--: owner has read/write, while group and others have read-only permission.

Can this calculator convert rwxr-xr-x to octal?

Yes. Enter a nine-character symbolic permission string and it updates the octal value and permission matrix.

Can I paste permissions from ls -l?

Yes. Paste the 10-character permission field, such as -rw-r--r--, -rwsr-xr-x or drwxrwxrwt. The calculator ignores the leading file-type character and converts the remaining permission bits.

Does it support setuid, setgid and sticky bits?

Yes. The calculator supports all three special bits and four-digit octal modes, and it carries those bits into the generated symbolic chmod assignment.

Can it generate symbolic chmod syntax?

Yes. In addition to the numeric command, it generates an exact class assignment such as chmod u=rwx,g=rx,o=rx file. Special bits appear as s or t in the appropriate class clause.

Does this run locally?

Yes. Permission calculation runs in browser JavaScript and does not send your values to the server.
