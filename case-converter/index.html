About this tool

Quickly normalize text for headings, code identifiers, filenames, URLs and editorial workflows.

Convert text between common case formats

This tool supports uppercase, lowercase, title case, sentence case, camelCase, PascalCase, snake_case and kebab-case. Paste text once, choose the target format and copy the converted result.

Editorial text

Use upper, lower, title or sentence case to normalize headings, labels and copied content before editing.

Code identifiers

camelCase and PascalCase are useful starting points for identifiers in languages and codebases that follow those naming conventions.

Data and filenames

snake_case and kebab-case can normalize words into predictable separators for data fields, file names and URL-style strings.

Runs locally

The conversion is performed in the browser without uploading the working text.

Review language-sensitive capitalization

Automated title and sentence casing is a mechanical transformation. Proper nouns, acronyms and language-specific capitalization may need manual correction after conversion.

Common case-conversion examples

Case conversion is useful when the same words must move between editorial copy, code identifiers and machine-friendly labels. For example, customer account status can become Customer Account Status for a heading, customerAccountStatus for a JavaScript-style identifier, customer_account_status for a data field, or customer-account-status for a filename or URL-like label.

What the converter does not infer

The tool changes casing mechanically; it does not understand brand spelling, acronyms, grammar or language-specific title conventions. Names such as iPhone, eBay, API, SQL or person and place names may need manual correction after conversion. When the output will be published, review it as editorial text rather than treating the conversion as final copy.

Useful workflow

Normalize the text here, then use the Slug Generator for URL paths or the Character Counter when a destination has a length limit. The text stays in the browser during conversion.
