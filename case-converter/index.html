Convert text for writing, labels and code identifiers

The Case Converter changes pasted text into UPPERCASE, lowercase, Title Case, Sentence case, camelCase, PascalCase, snake_case or kebab-case. Conversion runs in your browser, so ordinary pasted text does not need to be sent to a Smart Web Utility API.

Choose the case that matches the job

UPPERCASE and lowercase

Change every letter while preserving the rest of the text structure. These modes work well for normalization and quick cleanup.

Title Case

Capitalize the first letter of each whitespace-separated word and lowercase the remaining letters. This is a simple conversion, not an AP, Chicago or house-style title engine.

Sentence case

Lowercase the input and capitalize its first character. Review multi-sentence prose, proper nouns and acronyms manually after conversion.

Developer cases

Use camelCase, PascalCase, snake_case or kebab-case to turn simple phrases into common identifier and token styles.

How code-style conversion handles word boundaries

For camelCase, PascalCase, snake_case and kebab-case, the converter treats whitespace, underscores and hyphens as word boundaries before joining the pieces again. It does not understand your programming language, symbol table or naming conventions, so review punctuation, acronyms and domain-specific identifiers before committing a generated name to code.

Title case rules vary by style guide

Professional title case is not one universal algorithm. Editorial styles disagree about articles, conjunctions, prepositions and capitalization after punctuation. This tool uses a straightforward every-word capitalization rule. Use it for quick formatting, then apply the style guide required by your publication when editorial consistency matters.

Case conversion cannot infer meaning

Automatic casing cannot reliably know that a token is a brand name, surname, acronym or deliberately stylized term. A lowercase conversion can turn OpenAI into openai, while simple Title Case can alter acronyms. Treat the result as transformed text, not as a grammar or editorial correction.

Frequently asked questions

Does Title Case follow AP or Chicago style?

No. It applies a simple first-letter capitalization rule to each whitespace-separated word. Apply your required editorial style manually afterward.

Will Sentence case fix every sentence in a paragraph?

No. It lowercases the input and capitalizes the first character of the complete input. It does not perform grammar-aware sentence rewriting.

Is my text uploaded?

No. Case conversion runs in browser JavaScript on this page.
