Convert JSON to an Excel XLSX workbook

This converter accepts a top-level JSON array or a single JSON object and writes the resulting rows into a real Excel workbook. A JSON array of objects becomes multiple spreadsheet rows. A single object becomes one row. The workbook is generated in your browser using the pinned SheetJS Community Edition browser build.

How to convert JSON to Excel online

  1. Paste valid JSON into the editor or open a local .json file up to 5 MB.
  2. Select Convert JSON to parse the data and build a tabular preview.
  3. Review the row and column counts, especially flattened nested fields and array values.
  4. Select Download .xlsx to create json-to-excel.xlsx.

Example JSON array converted to Excel columns

JSON input:

  {
    "id": 101,
    "name": "Ada",
    "active": true,
    "address": {"city": "London", "country": "UK"},
    "tags": ["api", "json"]
  },
  {
    "id": 102,
    "name": "Linus",
    "active": false,
    "address": {"city": "Helsinki", "country": "Finland"},
    "tags": ["linux", "tools"]
  }
]

The generated sheet includes columns such as id, name, active, address.city, address.country and tags.

How nested JSON is handled

Nested objects are flattened with dot-separated paths. For example, {"address":{"city":"London"}} becomes a column named address.city. This keeps common API-style objects readable in a single worksheet without silently dropping nested fields.

Arrays are preserved as compact JSON text inside the cell. A generic converter cannot safely decide whether an array should become extra rows, extra worksheets or a many-to-one relation without knowing the application schema, so the page preserves the array instead of inventing a structure.

JSON values and Excel cell types

Numbers and booleans remain typed values when the workbook is generated. Null or missing properties appear as blank cells. Strings remain strings. This is different from a CSV export, where every value ultimately passes through a text representation.

JSON array vs single object

A top-level array is the best fit for tabular exports because each item can become one row. If the JSON contains one object, the converter creates one row from that object. Primitive array items are written into a single value column. Empty arrays are reported instead of producing a misleading blank workbook.

Limitations of JSON to XLSX conversion

Excel is a table-oriented format while JSON can represent arbitrary trees and nested collections. Deeply nested data, arrays of objects inside rows, or schemas that require multiple related sheets may need a custom transformation. This page intentionally creates one worksheet and preserves ambiguous arrays as JSON text rather than guessing.

The preview shows up to the first 50 rows for readability, while the downloaded workbook contains all parsed rows within the local 5 MB input limit.

Privacy and local file handling

The JSON file is read and parsed in your browser and is not submitted to a Smart Web Utility conversion API. The XLSX writer is loaded from the pinned SheetJS CDN dependency already documented in the repository. As with any external script request, the CDN receives normal request metadata, but it does not receive your JSON payload from this tool.
