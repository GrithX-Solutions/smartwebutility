Writing utility guide

Free online text tools for counting, formatting and clean URLs

This text tools hub covers everyday writing and publishing tasks: counting words and characters, changing letter case, creating readable URL slugs and generating placeholder copy. The utilities run in the browser where possible so drafts do not need to be uploaded for simple text transformations.

Word and character counting

Measure words, characters with and without spaces, sentences, paragraphs and lines when working with assignments, articles, forms and publishing limits.

Case conversion

Convert text between common writing and code-friendly cases instead of manually changing capitalization across long strings.

SEO-friendly URL slugs

Turn page titles and phrases into clean lowercase slugs that are easier to read and use in URLs.

Placeholder text

Generate Lorem Ipsum when a layout needs realistic text blocks before final copy is ready.

Choose the text metric that matches the limit

A word limit and a character limit are not interchangeable. Academic work and editorial briefs often specify words, while form fields, metadata and some platforms use character limits. Use the dedicated counter that matches the requirement instead of converting between the two approximately.

Text tools for SEO and content workflows

These utilities can support content production, but they do not replace search intent, editorial quality or technical SEO. Use the SEO tools when you need to inspect crawlability, metadata, structured data, canonicals or internal linking on a published website.
