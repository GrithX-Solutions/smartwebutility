Generate MAC addresses with explicit U/L and I/G bit control

This generator creates six-octet, 48-bit MAC addresses for development, virtualization, fixtures and network testing. By default it sets the universal/local (U/L) bit to locally administered and clears the individual/group (I/G) bit for unicast. You can change either control when a parser, protocol test or lab scenario needs a different bit pattern.

Local or universal-style

The U/L bit is the second least-significant bit of the first octet. Local mode sets it to 1. Universal-style mode clears it to 0 for test data, but a random cleared bit does not create a real IEEE-assigned OUI.

Unicast or multicast

The I/G bit is the least-significant bit of the first octet. Unicast clears it to 0 for an individual address; multicast sets it to 1 for a group address.

Cryptographic random bytes

Six octets come from the browser Web Crypto API. The generator then overwrites only the U/L and I/G control bits you selected; the remaining 46 bits stay random.

Bulk output

Create up to 1,000 unique values in one batch, optionally sort them, and export as lines, comma-separated text, JSON or CSV for fixtures and configuration workflows.

Universal-style output is not a vendor OUI assignment

IEEE-assigned Organizationally Unique Identifiers belong to their assignees. If you choose Universal-style, this tool only clears the U/L bit in a random first octet; it does not verify that the resulting prefix belongs to any organization and does not label it with a vendor name. Keep Locally administered selected for ordinary invented addresses unless your test specifically needs the universal bit cleared.

MAC address formatting

The same 48 bits can be displayed with colon separators such as 02:AA:BB:CC:DD:EE, hyphen separators such as 02-AA-BB-CC-DD-EE, Cisco-style dotted groups such as 02AA.BBCC.DDEE, or as 12 compact hexadecimal characters. Changing separators, letter case or list output re-renders the existing batch without generating different addresses.

Generated does not mean collision-free on your network

Bulk generation ensures values are unique within the current batch, but a randomly generated local MAC can still collide with an address already used elsewhere in your environment. Network administrators, hypervisors and orchestration platforms may have their own local-address allocation rules. Check the target environment before assigning a generated value.

MAC randomization and privacy

Modern client devices may randomize MAC addresses for privacy, but operating-system and wireless standards can apply additional policies beyond simply setting the local bit. This developer tool produces generic locally administered unicast MAC-48 values; it does not reproduce a specific phone, laptop, hypervisor or Wi-Fi privacy algorithm.

Do not use synthetic MACs to imply hardware identity

A generated local address is suitable for test fixtures or controlled local assignment, but it is not evidence of a physical adapter, manufacturer, device owner or location. Vendor lookup services should not be expected to identify a meaningful organization for these locally administered values.

Frequently asked questions

What type of MAC address does this generate?

It generates 48-bit MAC addresses. The default is locally administered unicast; you can also select universal-style administration or multicast for controlled test cases.

What does unicast versus multicast change?

It changes the I/G bit in the first octet. Unicast clears that bit for an individual address; multicast sets it for a group address.

Does Universal-style create a real vendor MAC?

No. It only clears the U/L bit. The random prefix is not an IEEE-assigned OUI and should not be presented as belonging to a real manufacturer.

Does it generate a real vendor OUI?

No. The local-administration bit is set, so the result is not presented as an IEEE-assigned globally unique vendor address.

Can I generate multiple MAC addresses?

Yes. Generate up to 1,000 unique values in one batch and export them as line-separated text, comma-separated text, JSON or CSV.

Which MAC address formats are supported?

Colon, hyphen, Cisco dotted and compact hexadecimal formats are available, with uppercase or lowercase output.

Are generated MAC addresses uploaded?

No. Generation runs locally in browser JavaScript.
