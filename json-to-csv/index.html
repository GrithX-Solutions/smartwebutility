JSON to CSV conversion: what this tool does

Convert a JSON object or an array of objects into CSV without uploading the payload. The tool builds a union of object keys for the header row and safely quotes CSV values when needed.

Objects and arrays

A single JSON object becomes one data row, while an array of objects becomes multiple CSV rows.

Union of keys

If objects contain different keys, the converter creates columns for the union of those keys and leaves missing values blank.

CSV-safe quoting

Commas, quotes and line breaks are escaped using standard double-quote CSV conventions.

Nested values retained

Nested objects and arrays are serialized as JSON strings inside CSV cells rather than silently discarded.

How to convert JSON to CSV

  1. Paste a JSON object or array of objects into the input editor, or open a local .json file.
  2. Select Convert, or use Ctrl/⌘ + Enter.
  3. Check the generated header row and confirm how nested values were serialized.
  4. Copy the CSV or download it as a .csv file for spreadsheet or import workflows.

Example json input and csv output

JSON input:

[{"name":"Ada","score":98},{"name":"Linus","score":95}]

CSV output:

name,score
Ada,98
Linus,95

Important conversion limitations

CSV is a flat table while JSON can be deeply nested. This converter keeps nested objects and arrays inside individual CSV cells as compact JSON. If you need flattened paths such as user.address.city, use a schema-aware transformation in your application.

When this converter is useful

Use JSON to CSV when API results, exports or test data need to be reviewed in a spreadsheet, imported into a tabular system, or shared with someone who does not work directly with JSON. It works best when rows have a broadly consistent object shape; deeply nested data may require a schema-aware flattening step.

Privacy and local file handling

The selected file is read with browser file APIs and limited to 5 MB in this implementation. Conversion happens on this page. The input content is not submitted to a Smart Web Utility conversion API.

Frequently asked questions

Can I convert a JSON object instead of an array?

Yes. A single object is treated as one CSV row.

How are nested objects handled?

Nested values are serialized as compact JSON inside the corresponding CSV cell.

Will commas inside values break the CSV?

No. Values containing commas, quotes or line breaks are escaped and wrapped in double quotes.
